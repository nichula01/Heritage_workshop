# Results Directory

Experiment outputs are written here locally and are ignored by Git.

Typical local output folders:

- `results/internvl25_2b_image_only_eval300/`
- `results/internvl25_2b_text_only_eval300/`
- `results/internvl25_2b_naive_multimodal_eval300/`
- `results/internvl25_2b_aer_v4_1_eval300/`
- `results/sample_size_robustness/`

Do not commit predictions, result CSV/JSON files, generated plots, PDFs, logs, or model outputs. When results are reported in a paper or release note, include the exact model version, dataset subset, seed, and command used to reproduce them.
